# 已实现的手机配对流程

交付者保留现有挂件中转授权和 Muse 凭据。手机打开挂件动态二维码 `/pair/?device=<公开引用>`；已有有效授权直接进入控制台，当前原 operator 的权限保持原样。

新手机点开始配对后，经官方受保护 BLE 服务读取公开引用，向 HTTPS 请求挑战，再提交到挂件。挂件本体已打开五分钟配对窗口才接受；显示两分钟有效的随机六位码，最多五次错误。手机输入后由挂件生成一次 HMAC 证明，服务端原子验证挑战、设备身份、码及临时浏览器 Cookie，直接签发 30 天滚动的受保护控制台会话，无第二组控制台登录码。

证明使用 `HMAC-SHA256(SHA256(device bearer), "SWPHONE1:" + challenge + ":" + code)`；公开引用为 `SHA256("SWPHONE-REF1:" + hex(SHA256(device bearer)))`。长期凭据及其哈希不出设备/后端。服务端使用原设备鉴权哈希验证，不新增秘密到固件或 BLE，不接触 Muse Token。官方 GATT ENC/AUTHEN 与系统首次蓝牙安全确认保持。

| 状态 | 行为 |
|---|---|
| 挂件无 Wi-Fi，手机能联网 | 可完成设备证明及手机会话；控制台显示等待联网，数据同步待网络恢复 |
| 首次管理手机 | 管理照片、显示和私人设置，Codex 默认只读；只有原控制端明确核对后可另行开启 Codex 控制 |
| 额外手机 | 默认只读；已有管理手机或原控制端可显式授予照片管理 |
| 当前有效手机再次扫码 | 直接进入对应控制台，不重新蓝牙或再输登录码 |
| 错误/过期/重放 | 设备与服务器分别限制尝试，过期需在本体重新开启，不重置账号 |
| 手机或挂件授权撤销 | 手机会话及事件通道失效；保留照片、Wi-Fi 和 Muse，不自动恢复被撤销权限 |

当前后端仍是私人单家庭相册/工作区模型，不声称提供多个收礼人账号的数据租户隔离。新手机会话绑定具体设备身份，但共享这套已有私人相册；不得把服务扩展成公开多租户产品而沿用该范围。管理员交接应先授予新管理手机，再撤销旧手机；撤销最后一位管理手机后由保留的原控制端恢复，不能重新扫码抢占所有者。

赠送前若需要远程 Codex，原控制端在设置的该手机旁点击「授权 Codex 控制」，核对确认完整权限范围。随后该手机可生成一次 Windows 绑定码、操作任务及完整审批；电脑仍须图形安装并由本人选择允许的工作区。管理手机不能自行开启或转授这项权限，降为只读会同时关闭。无需用第二个控制台登录码替换原手机会话。

网络入口为设置 → 网络及手机控制台网络页，密码仅通过 BLE 给官方 SDK。没有中转身份时明确提示交付准备未完成，不通过匿名云端注册降级认证。旧维护者六位控制台登录/设备授权流程保留以兼容已有安装，但不是普通手机的首次入口。

软件验证覆盖错误码、超时、重放、额外手机权限、撤销、离线状态及真实 HTTPS Cookie；浏览器测试中的 BLE 明确是夹具。实机输入事件通过真实 SDK 输入任务注入验证，不能代替手指按键/触屏。真实华为 BLE→设备证明及现场画面结果另见 PROGRESS。
